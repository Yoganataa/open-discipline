# Work Artifacts

Use this directory for durable workflow artifacts when a task warrants them.

Recommended structure:

    docs/work/<task-slug>/
    ├── intent.md
    ├── requirements.md
    ├── design.md          # L2/L3 when material design decisions exist
    ├── plan.md
    ├── tasks.md
    ├── verification.md
    └── walkthrough.md

Do not create every file for every task. Follow docs/WORKFLOW.md.

Artifacts are project evidence and handoff material. They are not a substitute for OpenDiscipline's tool-boundary enforcement or for actual validation.
